# Portfolio Website

ポートフォリオサイトのプロジェクトです。

## 概要

このプロジェクトは、Web開発者向けのモダンでレスポンシブなポートフォリオサイトです。

## 特徴

- レスポンシブデザイン
- スムーズなアニメーション
- モダンなUI/UXデザイン
- セマンティックHTML
- バニラJavaScript（フレームワーク不要）

## ファイル構成

```
my-portfolio/
├── index.html      # メインHTMLファイル
├── styles.css      # スタイルシート
├── script.js       # JavaScriptファイル
└── README.md       # このファイル
```

## セットアップ

1. このリポジトリをクローンまたはダウンロード
2. `index.html`をブラウザで開く

## カスタマイズ

- `index.html`でコンテンツを編集
- `styles.css`でスタイルをカスタマイズ
- `script.js`で動作をカスタマイズ
